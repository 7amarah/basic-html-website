# Basic HTML Website

A multi-paged, semantic, website built using plain HTML5.

This project was developed as part of the HTML Fundamentals learning path on [roadmap.sh](https://roadmap.sh/projects/basic-html-website), with a focus on understanding how to structure a website semantically using HTML, making the website multiple pages and learning the fundamentals of SEO by implementation.

## Live Demo

[View the Live Website](https://7amarah.github.io/basic-html-website/)

## Project Overview

The objective of this project is to create a structured, accessible, and search-engine-friendly multi-page website using only HTML, without relying on CSS frameworks or JavaScript.

The website has the following pages: Homepage, Projects, Articles, Contact that can be navigated to and from using the navigation bar at the top per page.

## Features

- Semantic HTML5 document structure.
- Multiple pages with a navigation bar.
- SEO metadata in the head of each page.
- Open Graph metadata for social media sharing.
- Contact page with form fields like name, email, message etc.

## Technologies Used

- HTML5
- Semantic HTML
- SEO metadata
- Open Graph metadata

## Getting Started

### Prerequisites

You only need:

- A web browser.
- A code editor (such as Visual Studio Code).
- Git (optional, for cloning the repository).

### Running Locally

1. Clone the repository:

   ```bash
   git clone git@github.com:7amarah/basic-html-website.git
   ```

2. Navigate into the project directory:

   ```bash
   cd basic-html-website
   ```

3. Open `index.html` directly in your browser.

Alternatively, open the project in Visual Studio Code and use the Live Server extension to preview the webpage. Make use of the navigation bar at the top tp move from one webpage to the other.

No package installation, build process, or development server is required.

## Deployment

The project is hosted using GitHub Pages.

To deploy:

1. Push the project files to the `main` branch of the public GitHub repository.
2. Navigate to the repository's **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Choose `main` and `/ (root)` as the deployment source.
5. Save the configuration.

GitHub Pages will publish the webpage.
